# CI/CD Final Project

## Project Overview

This project demonstrates the implementation of a Continuous Integration and Continuous Deployment (CI/CD) pipeline for a sample application.

## Technologies Used

* GitHub Actions for automated linting and unit testing
* Tekton for pipeline task management
* Red Hat OpenShift for pipeline execution and application deployment
* Python and Nose for application testing

## Objectives

* Automate code quality checks and unit tests.
* Define reusable CI/CD tasks using Tekton.
* Build and execute a pipeline on OpenShift.
* Verify successful execution and inspect application logs.

## Project Status

Project setup and CI/CD pipeline implementation in progress.
